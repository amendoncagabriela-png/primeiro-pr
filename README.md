# primeiro-pr

Repositório de treino para o primeiro pull request.

## Fluxo de um pull request

1. Criar um branch a partir do `main`.
2. Fazer a alteração e registrar um commit.
3. Enviar o branch para o GitHub (`git push`).
4. Abrir o pull request e revisar as mudanças.
5. Fazer o merge no `main`.
